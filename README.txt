مشروع "رسالة تحت النجوم" — دليل سريع
=========================================

الملفات:
- index.html   → صفحة القفل (الباسورد)
- love.html    → الصفحة الرئيسية (كل التجربة)
- photos/      → حطي صورك هنا (اختياري)

فين تعدّل النصوص؟
------------------
في كل ملف، هتلاقي جوه وسم <script> بلوك اسمه:

    const CONFIG = { ... }

ده المكان الوحيد اللي محتاج تعدل فيه. كل حاجة معلقة بالعربي جنبها
(الباسورد، العناوين، نص الآلة الكاتبة، الذكريات، تاريخ العلاقة،
رسائل صفحة الرسالة، وقائمة الأغاني).

خطوات سريعة:
1) افتحي index.html وغيّري:
   password: "12345"   → حطي الباسورد اللي عايزينه.

2) افتحي love.html وغيّري:
   - heroTitle / heroTypewriter → كلام الافتتاحية.
   - timeline → ذكرياتك، كل عنصر فيه date وcaption وimg
     (لو عايز صورة: حطي الصورة في مجلد photos وابعتي المسار
     مثلاً "photos/1.jpg"، ولو سبتيها فاضية "" هيظهر نجمة بدالها).
   - startDate → تاريخ بداية العلاقة (السنة-الشهر-اليوم).
   - anniversaryDate → سيبيها فاضية عشان تتحسب تلقائي = startDate + سنة،
     أو حطي تاريخ تاني لو عايز.
   - letterMessages → رسايلك، كل سطر في القايمة بيبقى فقرة منفصلة.
   - playlist → أغانيك [{ name: "اسم الأغنية", src: "رابط الملف" }]

مفيش أي حاجة تانية محتاجة تتلمس. لو عايز صور شغالة فورًا،
تقدر تستخدم أي رابط صورة مباشر في خانة img.
